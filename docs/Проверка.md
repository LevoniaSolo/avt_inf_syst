Для ранней истории AAPL и MSFT достаточно ряда выручки, а для SBER взяты доступные и однозначно сопоставимые статьи. В контрольном сравнении Ridge с `alpha=1` на тех же временных разбиениях дал MAPE 0,25% для учебного набора и 6,71% для реального списка. Для MVP оставлен линейный тренд. Объём реальной проверки составляет две годовые точки, поэтому вывод о качестве ограничен этим набором.

## Показ преподавателю

1. Запустите учебный набор и откройте `report.html` по пути из команды. Сверьте число прошедших бумаг и перейдите в карточку из скринера.
2. Выберите DEMO01 в списке карточек. Проверьте цену от 25.03.2025 и обе методики P/E. В квартале 31.03.2025 раскройте EBITDA. В отчёте EBIT равен 189,28, амортизация 71 и EBITDA 260,28. Налоговый блок показывает ETR 20%.
3. Сравните базу и сценарий в том же квартале. Проверьте прогноз следующего квартала и значение Naive. Откройте `formula_trace.csv` и `metrics.json` для сверки выгрузок.
4. Повторите запуск на реальном списке. Сверьте долю обработки и две допустимые точки в `metrics.json`. Для приёмки согласуйте с заказчиком контрольные наборы, фильтры, сценарий и минимальную историю.
